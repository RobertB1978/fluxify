# Manual required items

- [ ] Zainstalować binarkę Piper (`PIPER_BINARY`) oraz pobrać model i plik konfiguracyjny. Zaktualizować sumy SHA256 w `.env`.
- [ ] Zainstalować FFmpeg z obsługą `libmp3lame` (np. `apt install ffmpeg`).
- [ ] Uzupełnić realne wartości w `apps/backend/.env.example` (np. adresy CORS, katalog danych produkcyjnych).
